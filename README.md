# BCS-377-Midpoint-Project  

## Project Overview  
This is a To-Do website application built with HTML, CSS and JavaScript. The purpose is to help users organize their tasks based on importance and manage their time using a built-in focus timer.

### Features  
Task Management

- Add Tasks: Create new tasks and assign an importance level (High, Medium, or Low).
- Edit Tasks: Change the name of an existing task.
- Delete Tasks: Remove tasks from the list.
- Complete Tasks: Mark tasks as completed or restore them to active tasks.
- Change Importance: Update a task's importance level.
- Task Sorting: Automatically organize active tasks from High to Low importance, with completed tasks at the bottom.
- Input Validation: Prevent users from creating or saving tasks with empty titles.

Focus Timer

- Doing Now: Select a task to focus on.
- Custom Duration: Choose a timer duration from the available options.
- Start/Pause/Resume: Control the countdown timer.
- Reset: Reset the timer to the selected duration.
- Completion Popup: When the timer finishes, users can choose whether they completed their selected task.
